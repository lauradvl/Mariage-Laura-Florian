# Invitation mariage — Laura & Florian

Cette version intègre directement le Google Form dans la page.

1. Vérifier que le Google Form est publié et accessible aux répondants.
2. Tester `index.html`.
3. Pour publier : créer un repository GitHub, uploader `index.html`, `style.css` et `cover.png`.
4. Dans Settings > Pages : Deploy from a branch > main > / (root).
5. Le site sera disponible sur une URL `github.io`.

Les réponses restent gérées par Google Forms. Dans Google Forms > Réponses, vous pouvez associer une feuille Google Sheets.
